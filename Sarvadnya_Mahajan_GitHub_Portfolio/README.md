# Sarvadnya Mahajan — GitHub Pages Portfolio

This is the complete static website, ready to upload to a GitHub user-site repository. No build step, Node installation, backend, paid API, or ChatGPT login is required for this exported version.

## Publish

1. Create a public GitHub repository named YOUR-USERNAME.github.io. Replace YOUR-USERNAME with your exact GitHub username.
2. Extract this ZIP. Upload the CONTENTS of the extracted folder to the repository, not the ZIP itself or an enclosing folder. index.html must be at the top level, alongside assets/ and work/.
3. Commit the upload to the main branch.
4. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, main, and /(root). Click Save.
5. When GitHub finishes publishing, open https://YOUR-USERNAME.github.io.

This package assumes a user-site repository named YOUR-USERNAME.github.io. A repository with another name would publish under a subpath and would require link adjustments.

Official setup documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
